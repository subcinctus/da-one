# da-one

A simple static website for collecting and browsing dramatic low-angle cat photos.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Features

- Multi-file upload for JPG/PNG/WebP cat images.
- Responsive masonry-style gallery.
- Per-image remove button plus a clear-all action.
- All images are handled locally in your browser.
